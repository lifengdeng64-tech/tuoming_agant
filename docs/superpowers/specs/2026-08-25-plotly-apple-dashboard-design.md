# Plotly 仪表盘与 Apple 式极简 UI 设计

## 目标

在不替换 Streamlit、不改变本地脱敏与本地计算安全边界的前提下，将 Tuoming Agent 改造为 Apple 风格的极简数据工作台，并为本地数据制品生成 Plotly 交互式仪表盘。

改造后应让普通酒旅业务人员在不理解 SQL 或编程的情况下，快速查看营收、完成率、同比、RevPAR 等指标与趋势，同时保证原始数据不会为了绘图而离开本地。

## 方案选择

### 方案 A：仅修改 CSS，结果页插入少量图表

开发量最小，但只是换肤，不会形成真正的仪表盘信息层级；CSS 也会过度依赖 Streamlit 内部 DOM。

### 方案 B：Streamlit 设计系统＋独立仪表盘页＋Plotly 图表服务

保留现有本地应用、文件安全、脱敏、DuckDB 分析和导出链路；新增稳定的 UI token、可复用组件和独立的有界图表数据层。视觉提升明显，同时不需要重写应用。

### 方案 C：改用 React 前端

能做到更精细的交互和动画，但需新增 API 服务、身份与状态边界、打包链路及更多安全面，与本次目标不成比例。

**选定方案 B。**

## 信息架构

主视图调整为：

1. **概览**：工作区、数据和近期活动摘要。
2. **数据**：上传、检查、脱敏策略与数据源管理。
3. **分析**：自然语言需求、结构化计划与本地执行。
4. **仪表盘**：以某个脱敏制品为数据源，展示 KPI、趋势、分类对比和明细。
5. **结果**：原有制品预览、血缘、安全版和授权还原导出。
6. **设置**：模型、企业网络、备份恢复、更新和审计。

仪表盘不替代结果页：前者用于经营观察，后者用于数据核对与导出。

## 视觉设计

风格是“Apple-inspired”而不复制 Apple 商标、图标或产品页。

- 画布使用中性浅灰 `#F5F5F7`，主文字使用 `#1D1D1F`。
- 字体优先使用系统的 SF Pro / PingFang SC 字体栈。
- 信息卡片使用 18–20 px 圆角、极浅边框与克制阴影。
- 主色使用 `#0071E3`，成功、预警和错误只在表达状态时使用。
- 增大留白，减少边框与同级信息的竞争。
- 侧边栏使用半透明浅色背景，明确标记当前页面与本地安全状态。
- 移动宽度下将 KPI 收缩为两列，图表回落为单列。

## 仪表盘功能

### 数据源

用户从当前工作区的脱敏制品中选择一个数据源。仪表盘默认使用最新分析结果；没有分析结果时回退到最新上传制品。

### 自动生成

本地规则根据 schema 和有界统计选择图表，不为绘图额外调用大模型：

- 数值列生成最多 4 个 KPI；默认聚合方式为 `sum`，用户可改为 `mean` / `min` / `max` / `count`。
- 日期维度＋数值指标生成折线图。
- 分类维度＋数值指标生成排序柱状图，只显示 Top 12，其余合并为“其他”或不显示。
- 明细表显示最多 100 行。
- 没有合适的数值列时，显示可操作空状态，不生成误导性图表。

### 手动调整

页面顶部提供一组简化控件：日期维度、分类维度、指标、聚合方式、图表类型。调整只改变当前会话仪表盘，首版不增加持久化模板与多人共享。

### Plotly 交互

- 支持悬停提示、缩放、框选、图例开关和浏览器端图片下载。
- 图表主题与应用 token 共用颜色、字体、留白和提示框样式。
- 图表必须有明确标题、轴名、聚合方式与数据口径说明。
- 数据点最多 200，序列最多 4，防止浏览器卡顿和图表信息过载。

## 本地查询和安全边界

仪表盘不直接将完整 Parquet 读入 pandas。新增有界的本地图表查询服务，复用受控 DuckDB 运行时，仅返回生成 KPI 和图表所需的聚合结果。

- 只接受程序构造的列标识符、聚合枚举和有界筛选值。
- 不接受模型输出的 SQL，不接受用户手写 SQL。
- 单张图最多返回 200 行，明细最多 100 行。
- 图表使用脱敏制品；首版不提供仪表盘原值还原，避免交互图表无意暴露敏感信息。
- Plotly 在本地 Streamlit 中渲染，不使用 Chart Studio，不上传数据。

## 组件边界

1. `tuoming_agent/ui/theme.py`：设计 token、Plotly layout 主题和格式化函数。
2. `tuoming_agent/ui/components.py`：页头、KPI 卡、安全状态、空状态等通用组件。
3. `tuoming_agent/dashboard/models.py`：图表配置、聚合方式和有界结果模型。
4. `tuoming_agent/dashboard/service.py`：本地 schema 识别、默认配置、聚合查询与数据上限。
5. `tuoming_agent/dashboard/charts.py`：将有界表格转换为 Plotly Figure，不直接访问存储层。
6. `tuoming_agent/ui/dashboard.py`：Streamlit 仪表盘组装与会话状态。
7. `tuoming_agent/ui/styles.py`：只保留稳定的全局布局与品牌样式，减少对易变 DOM 结构的选择器。

## 错误与空状态

- 制品不存在或已被删除：回到数据源选择，不保留无效 session ID。
- 数据类型不适合：仅显示可用字段建议，不自动转换可能失真的数据。
- 资源上限命中：显示“请减少分类或时间粒度”，不回退到无界全量加载。
- 某张图失败：隔离显示该图错误，其他 KPI 和图表继续可用。

## 测试与验收

- 单元测试：schema 推断、列选择、聚合、Top N、空值、无穷值、日期粒度和资源上限。
- 安全测试：非法列名、伪造制品路径、非白名单聚合、超量数据点和图表原值还原均失败关闭。
- UI 测试：空工作区、默认制品、手动调整、局部错误、移动宽度与键盘焦点。
- 图表测试：Figure 仅含有界数据，颜色与标题符合主题，有效数据不因空值崩溃。
- 发布验收：Windows 便携版包含 Plotly 依赖并能离线渲染图表。

## 首版不包含

- 多用户共享仪表盘、在线发布或公网链接。
- 自由拖拽排版。
- 任意 SQL 或任意 Python 图表代码。
- Chart Studio 上传。
- 仪表盘中的敏感原值还原。
- 为了匹配 Apple 风格而复制 Apple 商标或受保护素材。
