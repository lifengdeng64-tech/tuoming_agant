# 200MB 大文件导入与分析设计

## 目标与边界

- 面向 16GB 内存的普通 Windows 电脑。
- CSV 单文件上限 200MB，XLSX/XLSM 单文件上限 100MB。
- 导入和单表分析均覆盖 200MB CSV，目标导入时间不超过 10 分钟。
- 大表合并保证主表不超过 200MB、辅助表不超过 50MB。
- 云端模型继续只生成 `AnalysisPlan`，不得生成 SQL、路径或 DuckDB 配置。

## 总体架构

大数据在导入后始终以 Parquet 制品留在磁盘。预览只读取样本，CSV 入库按批解析、检测和脱敏，通过 PyArrow `ParquetWriter` 增量写入。分析由每任务独立的 DuckDB 连接直接扫描 Parquet，并把结果直接写为新的 Parquet 制品；Pandas 只用于有限行预览、兼容测试和小型交互结果。

数据路径：

`上传流 -> 大小/磁盘检查 -> 样本预览 -> 分批解析与脱敏 -> Parquet -> DuckDB白名单执行 -> Parquet结果 -> 有限行预览`

## 文件导入

### 输入限制

根据扩展名在解析前检查字节数。CSV 超过 200MB、Excel 超过 100MB 或其他格式立即拒绝。导入前要求可用磁盘至少为输入大小的三倍再加 DuckDB 临时空间保留量，避免加密原件、Parquet 制品和临时文件把磁盘写满。

### 预览与策略确认

CSV 只读取前 500 行；Excel 使用只读工作簿读取每个 Sheet 的前 500 行。敏感字段自动检测和 UI 策略编辑只基于样本，但最终入库时对每个批次再次检测；发现样本阶段未配置的敏感列时终止导入，不产生正式制品。

### 流式落盘

CSV 使用 `pandas.read_csv(..., chunksize=50_000)`。每批完成策略校验、批量稳定 token 化、Arrow schema 对齐并追加到临时 Parquet，全部成功后原子替换正式制品。

Excel 使用 openpyxl 只读模式按行生成批次，避免把整个 Sheet 转成 DataFrame。公式读取缓存值，不执行宏。

原始上传使用流式 SHA-256 和 AES-GCM 加密写入临时文件，成功后原子替换，避免 `bytes -> 加密bytes -> DataFrame` 的多份完整内存副本。为兼容现有调用，`bytes` 输入包装为 `BytesIO`。

## DuckDB 安全执行

新增编译器把已有白名单操作编译成一条只读查询。编译器遵守以下规则：

- artifact ID 必须由本地仓储解析，且属于当前租户和工作区。
- 文件路径不接受模型或用户文本，只由已授权 artifact 记录提供。
- 列名必须存在于当前关系 schema，并用双引号转义。
- 筛选值、填充值等全部使用 DuckDB 参数绑定，不拼接进 SQL。
- 禁止任意 SQL、文件函数、扩展、ATTACH、COPY 输入、PRAGMA 和网络访问。
- merge 必须有等值键，禁止笛卡尔积；辅助 artifact 原始字节数不超过 50MB。
- 结果名只影响元数据，不参与 SQL 或路径生成。

每个任务创建独立内存连接，关闭外部访问，注册由本地代码打开的 Arrow/Parquet 数据源；设置 2GB 内存、最多 4 线程、4GB 临时目录上限。结果先写临时 Parquet，质量校验通过后才登记为正式 artifact。

## 质量、预览与导出

质量检查改为基于 Parquet 元数据和 DuckDB 聚合：列名唯一性、行数、lineage、数值非有限值、空值比例和输出放大率均不要求完整加载 DataFrame。

结果页只查询前 1000 行。脱敏版 CSV/Parquet 下载直接传递文件或流；还原版导出按 RecordBatch 分批还原并写出，Excel 导出受行数和估算内存上限限制，超限时提示使用 CSV。

## 错误与恢复

- 超限、磁盘不足和策略缺失在写正式记录前失败。
- 所有临时文件包含随机后缀；成功后原子替换，失败时清理。
- DuckDB 内存或临时空间超限归类为可理解的资源错误，不触发模型无限修复。
- 应用重启时可清理超过 24 小时的孤立临时文件。
- 现有 Agent 确认、修复次数、安全阻止和 SQLite 恢复语义保持不变。

## 测试与验收

- 单元测试覆盖大小边界、样本预览、分批落盘、标识符转义、值参数绑定、越权 artifact、合并大小限制和资源配置。
- 集成测试用生成数据验证 DuckDB 对全部白名单操作的结果与现有 Pandas 执行器一致。
- 回归测试保留现有小文件、脱敏、工作流和 UI 行为。
- 性能测试生成接近 200MB 的 CSV，记录峰值 RSS、导入时间、筛选/分组/排序时间；默认不进入快速测试套件，但作为发布验收命令提供。
