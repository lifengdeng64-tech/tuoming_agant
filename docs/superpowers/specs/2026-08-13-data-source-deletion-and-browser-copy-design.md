# 数据源安全删除与浏览器复制修复设计

## 目标

允许本地用户删除误上传的数据源，同时在删除存在关联分析的来源前展示完整影响并要求二次确认；恢复浏览器中 `Ctrl+C` 的正常复制行为，不再触发 Streamlit 的“清除缓存”开发者操作。

## 范围

本次删除入口以一次上传的 `files.id` 为单位。删除会覆盖该上传生成的所有数据集版本、源数据制品、由这些制品直接或间接产生的分析结果，以及引用这些制品的分析运行记录。不会删除其他上传、仍被其他版本使用的数据集、聊天文字或租户级 Token 映射。

## 删除影响分析

删除前由仓库服务在同一租户和工作区内计算闭包：

1. 找到目标文件的全部 `dataset_versions` 和源 `artifacts`。
2. 按 `artifacts.parent_ids_json` 递归找到所有下游分析制品。
3. 找到以闭包内制品作为 `source_artifact_id` 或 `result_artifact_id` 的 `analysis_runs`，以及其计划版本和执行尝试。
4. 找到引用闭包内制品的聊天附件；聊天文字保留，附件引用清空。
5. 返回文件名、数据集版本数、制品数、分析运行数和将释放的本地文件路径，供 UI 显示。

影响分析本身只读，不移动文件、不修改 SQLite。

## 用户交互

“数据 → 文件记录”区域为每个上传文件提供删除操作。第一次点击显示确认区：

- 无关联分析时，提示将删除原文件、数据集版本和本地制品。
- 有关联分析时，醒目标明关联分析运行数和下游结果数。
- 用户必须勾选“我了解关联内容也会删除”后，最终删除按钮才可用。
- 取消操作不产生任何持久化变化。

删除成功后界面重新加载，并显示删除摘要；失败时显示可操作错误，原数据保持可用。

## 原子性与文件恢复

删除由独立 `DataSourceService` 协调：

1. 对影响分析返回的每个受管文件路径做根目录归属和普通文件检查，拒绝符号链接、重解析点、目录或数据目录外路径。
2. 将加密原件和 Parquet 文件移动到数据目录内唯一的 `.trash/<operation-id>/`，记录原路径与回收路径。
3. 在单个 `BEGIN IMMEDIATE` SQLite 事务中，按外键依赖顺序删除计划版本、执行尝试、分析运行、字段策略、数据集版本、制品和文件；聊天附件改为 `NULL`；没有剩余版本的数据集一并删除。
4. 同一事务写入 `file_deleted` 审计事件，记录文件 ID、哈希前缀、删除计数，不记录原始数据。
5. SQLite 事务失败时，把所有文件恢复到原路径；事务成功后清理此次回收目录。

若数据库提交成功但进程在回收目录清理前崩溃，维护清理可安全删除未被 SQLite 引用的 `.trash` 内容。不会在数据库提交成功后恢复已删除文件，避免文件与元数据重新不一致。

## 引用和版本规则

- 如果某个逻辑数据集还有来自其他上传的版本，则保留数据集，并由现有版本查询自动显示剩余最高版本。
- 删除旧版本后不重新编号剩余版本，版本号保持历史稳定。
- 分析结果只要其任一祖先属于被删除来源，就纳入删除闭包。
- 聊天消息保留 `safe_content`，仅将已删除 `artifact_id` 置空。
- Token 映射为租户共享词库，可能仍被其他文件或用户查询使用，本次不做垃圾回收。

## 权限与安全

所有查询和删除必须同时约束 `tenant_id`、`workspace_id` 和目标 `file_id`。跨租户目标按未找到/未授权处理。调用者不能传入任意待删除路径；路径必须来自数据库影响分析，并再次验证位于配置的数据目录中。

## 浏览器复制修复

新增项目级 `.streamlit/config.toml`：

```toml
[client]
toolbarMode = "viewer"
```

`viewer` 模式隐藏 Streamlit 的重新运行、清除缓存和部署开发者操作，因此 `Ctrl+C` 保持浏览器原生复制行为。它不会禁用 `st.dataframe`、`st.data_editor` 或普通文本的复制能力，也不改变本地缓存实现。非主题配置变更需要重启 Streamlit 服务后生效。

## 测试与验收

- 仓库测试覆盖无分析来源、有下游分析来源、多版本数据集、聊天附件解绑、跨租户拒绝和事务回滚。
- 文件服务测试覆盖成功清理、数据库失败后恢复、数据目录外路径和链接路径拒绝。
- UI 测试覆盖影响提示、确认门槛、取消和成功刷新。
- 配置测试读取 Streamlit 配置并确认工具栏为 `viewer`。
- 最终运行全量 pytest、Ruff、compileall 和 `git diff --check`。

## 非目标

本次不提供单独删除任意分析结果、不回收 Token 映射、不删除聊天文字、不实现操作系统回收站，也不允许绕过二次确认直接级联删除有关联分析的数据源。
